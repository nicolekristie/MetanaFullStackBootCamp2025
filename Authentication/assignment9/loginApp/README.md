# Login Authentication App

A simple full-stack login authentication application built with React (frontend) and Node.js/Express (backend).

---

## Features

- User registration and login
- Password hashing for security
- JWT-based authentication
- Protected routes/pages
- Error handling 

---


## Getting Started

### 1. **Install dependencies**

```sh
npm install
```

### 2. **Set up the backend**

- Make sure your backend server is running (e.g., `node server/server.js`).
- Configure your database and environment variables as needed.

### 3. **Run the frontend**

```sh
npm run dev
```

### 4. **View in browser**

Open [http://localhost:5173](http://localhost:5173) to use the app.

---

## Usage

- Register a new user account.
- Log in with your credentials.
- Access protected pages after authentication.

---

## Security Notes

- Passwords are hashed before storage.
- JWT tokens are used for session management.
- Never commit real secrets or credentials to version control.
